# Goals

- I want to compare the query performance of clickhouse when
  - data is stored direclty within clickhouse and
  - when data is stored externally in S3 buckets in hive style partitions.

- These are the 2 options to compare

- Option 1:
  - The data is generated by an application generating OTEL metrics.
    - The OTEL metrics is exported as files by the otel collector to s3 buckets
    - Files in s3 are stored in hive style partitions in parquet format
  - A dashboard web application renders visualization of the metrics
    - Web application is built using react and echarts
    - Web application queries clickhouse for data
  - Clickhouse queries the S3 Data at runtime

- Option 2:
  - The data is generated by an application generating OTEL metrics.
    - The OTEL metrics is exported as files by the otel collector to s3 buckets
    - A lambda function writes the data into clickhouse every 10 mins
  - A dashboard web application renders visualization of the metrics
    - Web application is built using react and echarts
    - Web application queries clickhouse for data
